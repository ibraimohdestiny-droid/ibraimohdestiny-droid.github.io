PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named:
   ibraimohdestiny-droid.github.io
   (If that exact repository already exists, use it instead.)
2. Upload index.html, style.css, and the assets folder. Keep the folder structure.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. Your site address will be:
   https://ibraimohdestiny-droid.github.io/

GOOGLE SEARCH
A published website is not guaranteed to appear immediately in Google. Search engines may take days or weeks to discover and index it. You can later add the site to Google Search Console and request indexing.
